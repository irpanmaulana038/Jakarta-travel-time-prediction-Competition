# Jakarta-travel-time-prediction-Competition
# Overview
This project aims to predict travel time using a linear model, using linear regression model and python programming language.
This project is part of a competition by Digital Talent Scholarship and Yandex on training module **Linear Models in Machine Learning: Competition**

# Library
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Numpy

# Dataset
The dataset used in this project comes from the training module **Linear Models in Machine Learning: Competition** by Digital Talent Scholarship and Yandex.

# Result
- The results obtained for the training data were: 
Mean Squared Error: 19.793684747845393
R-squared: 0.9130469452268607
-Data test: 
Mean Squared Error: 18.42638026122061
R-squared: 0.918352035481975
